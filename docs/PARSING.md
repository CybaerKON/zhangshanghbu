# 课表与成绩解析

解析分两层：

- **页面层** `res/raw/page.js`：只解析当前页，把「表格 + 表头 + 记录 + 页签」原样交回；
- **模型层** `campus/Parse.java`：把原始数据映射成 `Table` / `Grade` / `Exam`，
  列的语义在这一层判断。

这样分工的好处：页面层不猜业务含义（学校加一列不会崩），模型层不碰 DOM（可以用
JVM 测试直接喂 JSON）。

## 1. 取数流程（`campus/Engine.java`）

```
fetchFirst(候选地址[])
  ├─ 依次 loadUrl 每个候选地址
  │    ├─ onPageFinished → 注入 page.js
  │    ├─ page.js 先判断「有可见密码框 / 地址是登录页」→ 返回 need=login
  │    ├─ 解析成功 → JSON 交回
  │    └─ 解析失败 → 换下一个地址，记录原因
  └─ 全部失败 → 打开教务首页，用 links 找出「课表 / 成绩 / 考试」入口，再试一次
                仍失败 → 把每一步的原因拼起来交给界面
```

上一版把「跳转」交给脚本用 `sessionStorage` 记步数，而每次跳转都换一个 WebView，
步数状态丢失，结果在候选地址之间来回空跳。现在跳转完全由原生控制：

- 每个候选地址都是一次明确的 `loadUrl`；
- 失败原因（地址 + 原因）会累积，最终展示给用户；
- 真实 URP 根地址（`https://v.hbu.cn/http/<enc>/`）在每次加载时被记下
  （`Portal.noteUrl`），后续接口直接拼它，不再从 `zhjw` 走一遍 302。

## 2. 课表

### 页面层

1. 在所有同源 frame 里找「最优课表表格」：`td` 数量够多、同时出现「星期 X」与多个「周」；
2. 用 `rowspan/colspan` 还原网格；找含 3 个以上「星期 / 周一」的表头行，得到列→星期映射；
3. 每个格子按 `<br>` / `</p>` / `</div>` 拆行：
   - 第 1 行是课程名（去掉 `_123456` 这类课程号后缀）；
   - 含「1-16周」的行是周次；
   - 含「楼 / 教室 / 号 / 数字」的行是教室；
   - 纯 2–4 个汉字是教师（名字里带「周」也认，如周颖）；
4. 节次取行首「第 3-4 节」，若没有则用行号；`rowspan=n` 的格子结束节次顺延 n-1；
5. 同一个 DOM 节点只计一次（rowspan 的格子会出现在多行）。

周次支持：`1-16`、`1-8,10-16`、`(单)`、`(双)`、`1,3,5`。

### 模型层

- 同名同教师聚合成一门课，多个时段挂在 `Course.sessions`；
- 同时段同周次的重复记录去重；
- 学期 id 来自页面文本（`2026-2027学年 第一学期` → `2026-2027-1`），
  取不到时按当前日期推断；
- 手动加的课 `source=custom`，重新导入时保留。

## 3. 成绩

### 五种口径分别取

| 口径 | 首选地址 | 说明 |
| --- | --- | --- |
| 全部及格 | `gradeLnAllAction.do?type=ln&oper=qbinfo` | 通常也带全部页签 |
| 课程属性 | 页签学到的 href → `oper=kcsx` | 按属性分组展示 |
| 方案成绩 | 页签学到的 href → `oper=pyfa` | 教务没有单独页面时明确提示 |
| 不及格 | 页签学到的 href → `oper=bxqinfo` | 按成绩/文字判定 |
| 本学期 | `bxqcjcxAction.do` | 通常一个学期一段 |

`Portal.learnTabs` 会把页面上「全部及格成绩 / 课程属性成绩 / 方案成绩 / 不及格成绩 /
本学期成绩」这些链接的真实 href 记下来，后续分类优先使用 —— 比猜 URL 稳得多。

### 列映射（`Parse.nameCol`）

URP 常见表头：`课程号 | 课程名称 | 课程属性 | 学分 | 成绩 | 绩点`。

如果按「包含课程」找列，第一个命中的会是**课程号** —— 这正是上一版成绩全是编号的原因。
现在的顺序：

1. 先找「课程名称 / 课程名 / 科目名称」；
2. 再找含「课程 / 科目」但**不含** 号 / 代码 / 编号 / 属性 / 性质 / 类别 / 学分 / 成绩 / 绩点 的列；
3. 都没有才兜底：取最长的、非纯数字、非属性词的一格。

其他列：学分、成绩（总评优先）、绩点、课程属性、学期，都按关键词找，不依赖列序。

### 拆行与判定

- 一格里有换行或分号分隔的多门课 → 拆成多条，其余字段沿用；
- 及格：文字含「不及格 / 未通过 / 缺考 / 作弊」→ 不及格；
  含「及格 / 通过」→ 及格；否则按分数 ≥ 60；
- 等级制（优秀 / 良好 / 中等 / 及格）换算成分数只用于算平均分，显示仍用原文。

## 4. 考试 / 校历

- 考试：`xskscxAction.do?oper=xskscx` 等候选，页面找「考试 / 考场 / 时间」表，
  列按关键词映射（课程、时间、地点、座位）；
- 校历：URP 没有校历页。应用里给的是按开学日期推算的「周次—日期」表，
  另提供「自动找学校校历」：打开教务处网站，按「校历」找链接并打开；
  找不到就明确说明学校的正式校历发布在「企业微信 → 教务服务」。

## 5. 排查

读不到数据时，界面会把失败原因拼出来，例如：

```
/zshbu/http/…/xskbcxAction.do → 这一页没有课表网格；/…/index.jsp → 这一页没有课表网格；
首页也没找到「课表」入口
```

对应处理：

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 所有地址都「没有课表网格」 | 未登录 / 被踢回登录页 | 点登录，重新走一遍 |
| 「需要重新登录」 | Cookie 过期 | 我的 → 重新登录 |
| 找到了页面但解析为空 | 页面结构改版 | 用「打开网页版」核对，按新结构改 `page.js` |
| 成绩名仍是编号 | 表头没有「课程名称」 | 把该页表头发出来，补一条映射 |

## 6. 测试

```bash
bash tests/run.sh
```

- `tests/js/test.js`：jsdom 造 URP 风格课表页 / 成绩页 / 登录页，
  跑真实 `page.js`，断言课程名、教师、教室、星期、节次、周次、表头、页签、登录判定；
- `tests/jvm/ParseTest.java`：喂 JSON 给 `Parse`，断言课程名不被课程号顶替、
  属性/学分/成绩/绩点正确、不及格口径、拆行、课表聚合与学期 id。
